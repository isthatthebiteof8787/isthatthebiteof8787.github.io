# ⚽ Match Organizer Bot – Documentation Website

This repository hosts the **documentation website** for the Match Organizer Bot – a feature‑rich Discord bot for managing football matches.

The site is built as a single‑page static website, designed for **GitHub Pages** and fully responsive.
