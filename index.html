Features

Reaction‑based Registration

Users simply click the ✅ reaction on a registration message to join the match. No commands needed!

Interactive Lineup Boards

Click any position to claim it, automatically moving to the sub queue if occupied. Real‑time updates.

Substitution Queues

Each position maintains its own sub list. When a player leaves, the first in queue takes their place.

Staff Role Management

Designate a staff role via /set_staff_role – only authorized users can start matches or clear boards.

Custom Lineups

Create any formation by specifying positions (e.g., GK, CB, CB, CM, ST) – up to 23 slots.

Single‑File & Lightweight

Everything fits in one Python script + SQLite database. Easy to deploy and maintain.

Commands

Both prefix (!) and slash (/) commands are supported.

/set_staff_role Staff

Set the role that has permission to manage matches. Only server owner or admin can use.

Example: /set_staff_role role:@Coaches
/friendly & !friendly Staff

Open registration for a friendly match. Posts a message with a ✅ reaction. Anyone can react to join.

Example: /friendly or !friendly
/lineup & !lineup Staff

Create an interactive lineup board. Optionally specify a formation.

Examples: /lineup (default 7v7)
/lineup 11 (11v11)
/lineup GK,CB,CB,LM,RM,ST (custom)
!lineup (prefix only) Staff

Same as slash, but in the message channel. Works with the same arguments.

Staff permissions: Server owner, members with Administrator, or members with the role set via /set_staff_role.

Usage Walkthrough

1
Start Registration – A staff member runs /friendly. The bot posts a message with a ✅ reaction and an @everyone ping.
2
Players React – Anyone can click the ✅ to register. The embed updates in real‑time showing all registered players.
3
Create Lineup – Staff uses /lineup to generate a board. Click any position to claim it.
4
Manage Subs – If a position is taken, clicking it puts you in the sub queue. When the occupant leaves, the first sub automatically moves up.
5
Clear or Customize – Staff can clear the entire board or use the ⚙️ Custom Lineup button to change positions on the fly.
